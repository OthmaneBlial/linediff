# Linediff documentation

Linediff compares UTF-8 text in a terminal and can add a Python definition summary to an exact line diff. The [README](../README.md) is the project overview. Development `main` has changes newer than the `v0.1.3` tag; check [release status](../README.md#linediff) before installing a published package.
