# Support

For usage questions, search the [FAQ](docs/faq.md), [quickstart](docs/QUICKSTART.md), and [open issues](https://github.com/OthmaneBlial/linediff/issues). If the answer is still unclear, open a usage question with your command, OS, Python version, install source, and a small public example.

For reproducible incorrect output, use the bug report template. For a suspected vulnerability, follow [SECURITY.md](SECURITY.md) and avoid a public report. No community chat or discussion forum has been verified for this project.
